> **Образовательная интерактивная sci-fi RPG-игра по курсу физики 8 класса.**  
> Защити космический город от астероидной угрозы, используя фундаментальные законы термодинамики, электричества, магнетизма и оптики!

---

## 🌟 Основные возможности

- 🎮 **Геймификация обучения**: Космическая аркада с физической базой — перехватывай астероиды, решая физические задачи, рассчитывая формулы и проходя интерактивные тесты.
- 📚 **Полный курс физики 8 класса (55 уровней)**:
  - 🛡 **1 вводный уровень**: Техника безопасности в кабинете физики.
  - 📖 **43 теоретических параграфа**: Подробные вопросы и задачи по всем разделам программы.
  - 🔬 **11 виртуальных лабораторных работ**: Моделирование физических процессов и экспериментов.
- 🌐 **Мультиязычность**: Полная поддержка трёх языков с мгновенным переключением в интерфейсе:
  - 🇷🇺 Русский (`RU`)
  - 🇬🇧 Английский (`EN`)
  - 🇰🇿 Казахский (`KK`)
- 👤 **RPG-профиль пилота**: Настройка позывного пилота и выбор уникальных скинов космического корабля.
- 📖 **Интерактивный учебник и конспект**: Встроенный краткий справочник, расширенная теория по каждому параграфу и возможность экспорта конспекта в PDF.
- 👨‍🏫 **Режим учителя (Teacher Mode)**: Конструктор пользовательских уроков и заданий, управление тестовыми базами и локальное сохранение.
- 💾 **Автономность и сохранение**: Работает полностью в браузере без серверов, сохраняет прогресс, рекорды и настройки в `LocalStorage`.
- 📱 **Адаптивность и поддержка Touch**: Удобное управление как на ПК (клавиатура/мышь), так и на смартфонах и планшетах.

## 🕹 Управление в игре

- **Стрелки влево / вправо** или клавиши **A / D**: Перемещение ракеты-защитника.
- **Пробел (Space)** или клик по сектору: Активация щита / захват цели.
- **Клавиша P** или кнопка **⏸**: Пауза и вызов меню.
- **Сенсорные экраны**: Наэкранные стрелки и тап по кнопкам действий.

## 🚀 Быстрый запуск

Проект является полностью клиентским (Pure Vanilla JavaScript) и **не требует установки сторонних библиотек, компиляции или сборки**.

### Вариант 1. Локально через браузер
Просто откройте файл `index.html` (или `physics-quest-8-grade.html`) в любом современном браузере (Chrome, Firefox, Edge, Safari, Яндекс.Браузер).

### Вариант 2. Локальный сервер (рекомендуется)
```bash
# С помощью Python 3
python3 -m http.server 8080

# Или с помощью Node.js (npx)
npx serve .
```
Откройте в браузере: `http://localhost:8080`

## 🌐 Публикация на GitHub Pages (Бесплатный хостинг)

Вы можете опубликовать игру онлайн за 1 минуту:

1. Создайте репозиторий на GitHub (например, `physics-quest-8-grade`).
2. Загрузите файлы репозитория (`index.html`, `README.md`, `LICENSE` и др.).
3. Перейдите в **Settings** репозитория ➔ вкладка **Pages** (слева).
4. В блоке **Build and deployment**:
   - **Source**: выберите `Deploy from a branch`
   - **Branch**: выберите `main` (или `master`), папку `/ (root)`
   - Нажмите **Save**.
5. Через 30–60 секунд игра станет доступна по адресу:  
   `https://<ваш-логин-github>.github.io/<название-репозитория>/`

*(В репозиторий также включен готовый GitHub Actions workflow `.github/workflows/pages.yml` для автоматического деплоя).*

## 🛠 Технологический стек

- **HTML5**: Семантическая разметка, Canvas, аудио/визуальные контейнеры.
- **CSS3**: Неоновый sci-fi дизайн, CSS Grid / Flexbox, анимации, адаптивные медиа-запросы.

  - Игровой движок на `requestAnimationFrame`
