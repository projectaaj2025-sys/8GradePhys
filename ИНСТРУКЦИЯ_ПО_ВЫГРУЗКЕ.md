# 📋 Пошаговая инструкция по выгрузке на GitHub

Этот проект полностью подготовлен для размещения на GitHub и мгновенного запуска через **GitHub Pages** (бесплатный хостинг для статических сайтов).

---

## 🎯 Вариант 1: Через командную строку (Git CLI) — самый быстрый способ

### Шаг 1. Создайте новый репозиторий на GitHub
1. Перейдите на сайт [github.com](https://github.com) и войдите в свой аккаунт.
2. Нажмите зелёную кнопку **«New»** (или значок **`+`** в правом верхнем углу ➔ **New repository**).
3. Введите название репозитория, например: `physics-quest-8-grade`.
4. Оставьте репозиторий **Public** (публичным).
5. **Важно:** Не ставьте галочки у *«Add a README file»*, *«Add .gitignore»* и *«Choose a license»* (они уже подготовлены в проекте).
6. Нажмите **«Create repository»**.

### Шаг 2. Инициализируйте Git и отправьте файлы
Откройте терминал в папке с проектом и выполните команды (замените `YOUR-USERNAME` на ваш логин на GitHub):

```bash
# 1. Инициализация локального репозитория
git init -b main

# 2. Добавление всех файлов в индекс
git add .

# 3. Создание первого коммита
git commit -m "Initial commit: Physics Quest 8 Grade"

# 4. Привязка удаленного репозитория GitHub (замените YOUR-USERNAME на ваш логин)
git remote add origin https://github.com/YOUR-USERNAME/physics-quest-8-grade.git

# 5. Отправка файлов на GitHub
git push -u origin main
```

## 🖥 Вариант 2: Через интерфейс сайта GitHub (Без консоли)

1. Создайте новый репозиторий на GitHub (как описано в Шаге 1).
2. На странице созданного пустого репозитория нажмите на ссылку **«uploading an existing file»** (или перетащите файлы в окно браузера).
3. Перетащите все файлы проекта:
   - `index.html`
   - `physics-quest-8-grade.html`
   - `README.md`
   - `LICENSE`
   - `.gitignore`
   - `package.json`
   - папку `.github`
4. Внизу страницы в поле *Commit changes* напишите `Initial commit` и нажмите зелёную кнопку **«Commit changes»**.

## 💻 Вариант 3: Через GitHub Desktop (Графическое приложение)

1. Скачайте и откройте [GitHub Desktop](https://desktop.github.com/).
2. Выберите **File ➔ Add Local Repository...** и укажите папку с проектом.
3. Если появится предложение создать репозиторий (*create a repository here*), подтвердите создание.
4. В левом нижнем углу введите описание коммита (например, `Initial commit`) и нажмите **Commit to main**.
5. Нажмите кнопку **Publish repository** в верхней панели для выгрузки на GitHub.

## 🌐 Как включить онлайн-игру через GitHub Pages (Бесплатный сайт)

После того как файлы загружены в репозиторий:

1. В вашем репозитории на GitHub перейдите во вкладку **Settings** (Настройки).
2. В левом боковом меню выберите пункт **Pages** (в разделе *Code and automation*).
3. В блоке **Build and deployment**:
   - В поле **Source** выберите: `Deploy from a branch`.
   - В поле **Branch** выберите ветку `main` (или `master`) и папку `/ (root)`.
   - Нажмите кнопку **Save**.
4. Подождите 1–2 минуты. Обновите страницу: сверху появится зелёная плашка с адресом вашего сайта:
   `https://<ваш-логин>.github.io/physics-quest-8-grade/`
5. Перейдите по ссылке — игра запустится онлайн и будет доступна для всех учеников и учителей на любых устройствах!
